- **fix(antigravity):** Claude models served through Antigravity Cloud Code never reasoned. The OpenAI to Antigravity translator deleted `generationConfig.thinkingConfig` for every `claude-*` model, on the assumption that the Cloud Code Claude endpoint rejects the Gemini-shaped field. Verified against `daily-cloudcode-pa.googleapis.com` that it does not: an otherwise identical request carrying `thinkingConfig` returns 18 thought parts where one without it returns 0, for both `claude-opus-4-6-thinking` and `claude-sonnet-4-6`. The strip is removed and Claude now defaults to high-effort thinking when the caller expresses no preference; `reasoning_effort` (`none`/`low`/`medium`/`high`/`xhigh`) and an explicit `thinking.budget_tokens` both control it, and `none` is newly reachable as a real off switch. The 16384 output cap can no longer clamp `maxOutputTokens` below the thinking budget, because `thinkingBudget >= maxOutputTokens` is exactly what upstream rejects with a 400: the old clamp produced the very error it was meant to avoid. Root-level `thinking`/`reasoning_effort` are still stripped, since those genuinely break the Cloud Code schema (#1926) (#24).
