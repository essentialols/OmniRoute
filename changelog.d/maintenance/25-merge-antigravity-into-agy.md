- **refactor(antigravity):** `agy` and `antigravity` were two registrations of one backend: same Cloud Code endpoint, same executor, same OAuth client, and the same Google accounts with the same project ids. The split tracked two quota and cooldown pools that could never see each other's consumption, and advertised 34 catalog entries for 19 real models. They are now one provider under `agy`, carrying the union of both catalogs (gaining `claude-sonnet-5`, `gemini-3-pro-preview`, `gemini-3-pro-image-preview` and `gemini-2.5-computer-use-preview`). The retired `antigravity` id keeps resolving through a new `LEGACY_PROVIDER_ID_MAP` so stored connections, `antigravity/<model>` references, shipped combo presets and `omniroute login antigravity` all still work; it is simply no longer advertised as a model prefix. Behaviour that had been wired only to the old id is ported across, so the surviving provider does not silently lose it: family-scoped quota, 429 retry-after parsing, cooldown classification, recoverable-403 handling, stream-readiness and pre-response-timeout fallback, pricing (`agy` previously reported zero cost), the static catalog, and image-generation and Google Flow video credentials. Migration `121` folds `provider='antigravity'` onto `agy` across every provider-keyed table (#25).
